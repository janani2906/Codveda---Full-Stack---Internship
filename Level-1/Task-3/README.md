# Frontend with HTML, CSS and JavaScript

## Project Description

This project demonstrates how to build a responsive frontend webpage using HTML, CSS, and JavaScript.

The application fetches user information from a REST API using the Fetch API and displays the data dynamically in attractive cards.

## Features

- Responsive Design
- Fetch API
- Dynamic User Cards
- Loading Message
- Error Handling
- Modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
